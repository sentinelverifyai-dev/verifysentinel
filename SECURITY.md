# Security

This page is for problems with the service itself, such as a way to reach someone else's account, data that
should not be visible, or a way around the limits. A picture that fools the detector is not a security issue.
That is [the challenge](CHALLENGE.md).

To report a problem, email **sentinelverifyai@gmail.com** with "Security" in the subject. We reply within 48
hours. Please give us time to fix it before telling others.

While looking, please:
- don't touch accounts or data that aren't yours;
- don't run load or stress tests against the live service;
- don't try to read or copy the detector itself.
